Testar varje testfall en efter en i en loop. Ifall något testfall misslyckas stannar processor med en asser.
Varje testfall skrivs ut ifall den lyckas eller misslyckas till UART terminalen. Även nummer av loopar som har passerat.
Nummer av loopar som har passerat skrivs ut på den fysiska hex display på FPGA kortet också.

I test_setup.h är test hw specific testplatform aktiv.
SIERRA_FULL_TEST_HW_PLATFORM -> 1

Testfall :
 - test 001   -> task creation

 - test 004   -> task startar i correct priority
 - test 005   -> task startar i blocking state
 - test 006   -> task semaphore och release
 - test 006b  -> task semaphore och release
 - test 007   -> flaggor
 - test 008   -> periodiska schemaläggaren startar task i rätt ordning
 - test 009   -> sierras delay funktion
 - test 010   -> task ändra prioritet under körning.
 - test 011   -> task blocking 2
 - test 012   -> task prioritet 2. Kontrollerar att verkligen prioriteten ändrades.
 - test 012b  -> task prioritet 3. Stress test. Måste ändra prioritet snabbt.

Ett problem med nios v/g är att den kan köra testfall snabbare än vad jtag UART kan skriva ut.
För lösa UART buffert overflow problem tilldelas funktionerna agstu_print_char, agstu_print_string, agstu_int_to_string.
Skriver snabbt direct till UART bufferten det som överflödar ramlar bort och visas inte i juart-terminalen.

agstu_print_char(char c)      - Skriv ut ASCII tecknet c direkt till jtag UART
agstu_print_string(char* str) - Skriv ut alla ASCII tecken från std som är en char array (string). Som en vanlig string ska sissta elementet avslutas med NULL ('\0')
agstu_int_to_string(int nr)   - Konverterar nr som är en 32 bit int till en char array (string). max 10 tecken (32 bit kan inte bli större). (todo kan visa '-' tecken).
